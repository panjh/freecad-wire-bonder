# 样条曲线控制点定义

打线弧由 **5 个控制点** A → B → C → D → E 描述，经 FreeCAD 的
`Part.BSplineCurve.interpolate()` 插值成一条**严格穿过全部控制点**的平滑样条。

```
                    C  (顶点)
                    *
                  /   \
                 /     \
    B *         /       \         * D
     /         /         \         \
    /         /           \         \
   A *-------/             \---------* E
  起点                                终点
```

---

## 1. 局部坐标系

样条的输入是**平面内的二维坐标** `(u, v)`：

| 轴 | 含义 | 取值 |
| --- | --- | --- |
| `u` | 沿两焊盘质心连线的距离，从起点 A 起算 | `0 → L` |
| `v` | 相对该连线的**高度**（沿走线平面的法向） | `0 → clearance` |

之后再映射回三维：`P(u, v) = A + u·x + v·y`，其中 `x` 是连线方向、`y` 是走线平面内的
"向上"方向。因此下文所有公式都与零件朝向无关。

---

## 2. 五个控制点

| 点 | 名称 | `u` | `v` |
| --- | --- | --- | --- |
| **A** | 起点（第一个焊盘） | `0` | `0` |
| **B** | 上起点 | `lead · cos(rise)` | `lead · sin(rise)` |
| **C** | 顶点 | `peak_ratio · L` | `clearance` |
| **D** | 上终点 | `L − lead · cos(fall)` | `lead · sin(fall)` |
| **E** | 终点（第二个焊盘） | `L` | `0` |

### A：起点

固定落在第一个焊盘质心。

### B：上起点

从 A 沿 **`rise_angle` 方向的射线**前进 `lead_distance` 得到：

```
B = A + lead_distance · (cos(rise_angle), sin(rise_angle))
```

### C：顶点

```
C = (peak_ratio · L, clearance)
```

`u` 方向由 **`PeakRatio`** 决定（在两焊盘之间），高度由 **`Clearance`** 决定。

### D：上终点

从 E 沿 **`fall_angle` 方向的射线**（朝向 A）前进 `lead_distance` 得到：

```
D = E − lead_distance · (cos(fall_angle), −sin(fall_angle))
  = (L − lead·cos(fall),  lead·sin(fall))
```

> 规范原文写的是 `CD = LeadDistance`；这里实现为 **`ED = LeadDistance`**，
> 以与 `AB = LeadDistance` 对称 —— 两者都是"从焊盘出发沿射线的距离"。
> 注意 `CD` 与实际距离并不相等（例如默认参数下 `CD ≈ 379 µm` 而 `ED = 30 µm`）。

### E：终点

固定落在第二个焊盘质心。

---

## 3. 角度的定义

`RiseAngle` 与 `FallAngle` 都以 **A–E 连线为基准**（不是以竖直方向为基准）：

| 角度 | 含义 |
| --- | --- |
| **0°** | 沿 A–E 连线，指向**另一个**焊盘（水平，不抬起） |
| **45°** | 斜向 45° |
| **90°** | **垂直于** A–E 连线，即正上方（切向竖直） |

两个角度的"指向"互为镜像：

* `RiseAngle` 从 A 出发指向 E 一侧；
* `FallAngle` 从 E 出发指向 A 一侧。

因此**角度直接表达"线以多陡的姿态离开/落到焊盘"**，这正是工艺上要调的量 ——
比原先的"高度比例"直观得多。

> 角度被限制在 **0°–89°** 之间（`MAX_ANGLE = 89`）：恰好 90° 时 `cos = 0`，
> B（或 D）的 `u` 会与 A（或 E）重合，样条要求的"参数严格递增"就不再成立。

---

## 4. 参数与默认值

| 参数 | 属性 | 默认 | 作用 |
| --- | --- | --- | --- |
| 弧高 | `Clearance` | 500 µm | 顶点 C 的高度 |
| 顶点位置 | `PeakRatio` | 0.42 | 顶点在连线上的位置比例 |
| 出线角度 | `RiseAngle` | **75°** | B 点所在射线的角度 |
| 落线角度 | `FallAngle` | **20°** | D 点所在射线的角度 |
| 进出线距离 | `LeadDistance` | **30 µm** | `AB` 与 `ED` 的长度 |

配对的"高度"由角度与距离**推导**出来，不再是独立参数：

```
B 的高度 = lead · sin(rise_angle)
D 的高度 = lead · sin(fall_angle)
```

---

## 5. 特性与取舍

**优点**

* **参数含义直观**：直接设定进出线角度，与工艺语言一致；
* **控制点少**（5 个），曲线平滑、过冲小 —— 实测顶点高度误差仅 **+0.0%~+0.8%**；
* 距离 `AB` 与 `ED` 精确等于 `LeadDistance`（不受角度影响）。

**代价（与 8 点方案相比）**

* **没有真正的平顶**：只有 C 一个点达到弧高，样条在该处呈圆弧过渡，
  实测"顶部 2% 以内"的平台宽度约 **110–160 µm**（参考图约 210 µm）；
* **下降段不是直线**：C 与 E 之间只有一个控制点 D，样条必然外凸，
  实测相对直线的最大偏差约 **14%**（8 点方案借助共线点可做到 3%）。

> 这两点是"控制点数量少"的必然结果。`scripts/scan_angles.py` 可复现上述扫描数据。

**自动保护**：若 `lead · cos(angle)` 过大（例如角度接近 0° 而距离很长），
B（或 D）的 `u` 可能越过 C，代码会把水平分量夹紧到 C 之前（或之后）留 2% 余量，
保证 5 个控制点的 `u` **严格递增**。
