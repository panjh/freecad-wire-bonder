# 样条曲线控制点定义

打线弧由 **`4 + N` 个控制点**描述，经 FreeCAD 的 `Part.BSplineCurve.interpolate()`
插值成一条**严格穿过全部控制点**的平滑样条。

> **v0.14.0 起**：控制点的坐标不再沿"两焊盘质心连线"布置，而是按**打线机视角**
> 布置 —— 水平方向取**起点焊盘平面与走线平面的交线**，高度方向取该水平线在走线
> 平面内的垂线（正方向朝起点焊盘法线一侧）。角度与高度因此都以**水平面**为基准。
> 两个焊盘等高时，结果与旧方案**逐位相同**。

```
                            *  *  *  *        ← 弧线控制点（N 个，可 1..多个）
                   B      /          \      D
                    *    /            \    *
                   /    /              \    \
                  /    /                \    \
                 A *--/                  \----* E
                起点                            终点
```

- **A / E**：两端焊盘质心（固定）；
- **B / D**：由出线/落线角度与进出线距离决定（固定）；
- **中间 N 个"弧线控制点"**：由参数 `LoopPoints` 给出，`N = 1` 时即传统的弧顶。

`N = 1` 时共 **5 个**控制点（旧的 5 点方案），`N = 4` 时共 8 个，以此类推。

---

## 1. 走线坐标系（horizontal frame）

样条的输入是**平面内的二维坐标** `(x, y)`，由 `core.horizontal_frame()` 建立：

| 轴 | 含义 |
| --- | --- |
| `x` | **水平轴**：起点焊盘平面（`n₁`）与走线平面（`z`）的**交线**方向；`0 → span_x` |
| `y` | **高度轴**：`x` 在走线平面内的垂线，正方向取**与起点焊盘法线 `n₁` 接近**的一侧；`0 → 各控制点高度` |

```
x = normalize(y × z)            y = normalize(n₁ − (n₁·z)·z)
A = C₁                          E = (span_x, span_y) = (L·xdir·x, L·xdir·y)
```

**为什么这样取**：`x` 就是"焊盘表面上、朝着另一个焊盘"的方向，与打线机的编程
基准一致；只要焊盘是平的，无论另一个焊盘高低如何，同一条弧线的水平基准都不变。
`y` 取 `n₁` 的面内分量，保证 `+y` 永远**背离焊盘**，正高度不会扎进焊盘里。

两个焊盘等高且朝向相同时，`x` 退化为 `C₁→C₂`、`y` 为正上方，此时与 v0.13.0 的
"沿质心连线 + 相对连线高度"**完全等价**（实测逐位相同，差 < 1e-12）。

> **退化情形**：`n₁ // z`（起点焊盘平面与走线平面平行，交线不存在）时无法定义水平
> 方向，代码会抛 `WireBondError` 并提示换一个平面与走线平面相交的焊盘。

## 2. 控制点

| 点 | 名称 | `x` | `y` |
| --- | --- | --- | --- |
| **A** | 起点（第一个焊盘） | `0` | `0` |
| **B** | 上起点 | `lead · cos(rise)` | `lead · sin(rise)` |
| **第 i 个弧线控制点** | 用户给出 | `ratioᵢ · span_x` | `heightᵢ`（mm） |
| **D** | 上终点 | `span_x − lead · cos(fall)` | `span_y + lead · sin(fall)` |
| **E** | 终点（第二个焊盘） | `span_x` | `span_y` |

其中 `span_x` 是两焊盘的**水平距离**（`C₁→C₂` 在水平轴上的投影，恒为正），
`span_y` 是 E 相对 A 的**高度差**（第二个焊盘更低时为负）。

### A：起点

固定落在第一个焊盘质心。

### B：上起点

从 A 沿 **`rise_angle` 方向的射线**前进 `lead_distance` 得到（角度以水平轴 `x`
为基准，`0°` 水平、`90°` 正上方）：

```
B = A + lead_distance · (cos(rise_angle), sin(rise_angle))
```

### 弧线控制点（`LoopPoints`）

列表中的每一项是 `(ratio, height)`：

```
点ᵢ = (ratioᵢ · span_x, heightᵢ)
```

- `ratioᵢ ∈ [0, 1]`：沿**水平跨度**的位置比例（`0` = 起点 A，`1` = 终点 E）；
- `heightᵢ`：该点**相对 A 点水平面**的绝对高度，单位 mm（面板按 µm 输入）。
  注意它不是"相对 A–E 连线"的高度 —— 两个焊盘不等高时两者不同，且只有前者
  才与打线机的编程基准一致。

**一个点**即传统的弧顶：`ratio` 相当于旧的 `PeakRatio`，`height` 相当于旧的
`Clearance`，此时结果与旧的 5 点方案**逐位一致**。

**多个点**可以描述平顶或直线下降，例如：

```
0.30,0.2;0.40,0.2;0.60,0.2;0.70,0.2      ← 中段等高的近似平顶
0.30,0.2;0.50,0.24;0.70,0.20             ← 三点共线可压平下降段
```

### D：上终点

从 E 沿 **`fall_angle` 方向的射线**（朝向 A）前进 `lead_distance` 得到：

```
D = E − lead_distance · (cos(fall_angle), −sin(fall_angle))
  = (span_x − lead·cos(fall),  span_y + lead·sin(fall))
```

> 规范原文写的是 `CD = LeadDistance`；这里实现为 **`ED = LeadDistance`**，
> 以与 `AB = LeadDistance` 对称 —— 两者都是"从焊盘出发沿射线的距离"。
> 注意 `CD` 与实际距离并不相等（例如默认参数下 `CD ≈ 379 µm` 而 `ED = 30 µm`）。

### E：终点

固定落在第二个焊盘质心。

## 3. 角度的定义

`RiseAngle` 与 `FallAngle` 都以**水平面**（水平轴 `x`）为基准：

| 角度 | 含义 |
| --- | --- |
| **0°** | 水平，指向**另一个**焊盘（不抬起） |
| **45°** | 斜向 45° |
| **90°** | 正上方（切向竖直） |

两个角度的"指向"互为镜像：

* `RiseAngle` 从 A 出发指向 E 一侧；
* `FallAngle` 从 E 出发指向 A 一侧（即水平轴负方向）。

这正是打线机编程的基准，因此**角度直接表达"线以多陡的姿态离开/落到焊盘"**，
且**不随两焊盘的高度差变化**（旧方案以 A–E 连线为基准，焊盘不等高时同一角度会
得到不同的实际陡峭程度）。

> 角度被限制在 **0°–180°** 之间（`MAX_ANGLE = 180`）：恰好 90° 时 `cos = 0`，
> B（或 D）的 `x` 会与 A（或 E）重合，样条要求的"参数严格递增"就不再成立。

## 4. 参数与默认值

| 参数 | 属性 | 默认 | 作用 |
| --- | --- | --- | --- |
| 弧线控制点 | `LoopPoints` | `0.4,0.2`（即 ratio 0.40、高 200 µm） | 中间 N 个点 |
| 出线角度 | `RiseAngle` | **75°** | B 点所在射线的角度 |
| 落线角度 | `FallAngle` | **15°** | D 点所在射线的角度 |
| 进出线距离 | `LeadDistance` | **30 µm** | `AB` 与 `ED` 的长度 |

B / D 的"高度"由角度与距离**推导**出来，不再是独立参数：

```
B 的高度 = lead · sin(rise_angle)
D 的高度 = span_y + lead · sin(fall_angle)
```

> **属性形式**：`LoopPoints` 是 `App::PropertyString`，文本形式为
> `"ratio,height;ratio,height;..."`（例如 `0.4,0.2;0.6,0.18`），
> 分隔符固定用 `;` 与 `,`（不随区域设置变成小数逗号）。
> 面板提供**表格编辑器**逐行增删，无需手写文本。

### 从旧版本升级

旧对象上的 `Clearance`（弧高）与 `PeakRatio`（弧顶位置）在首次重算时会自动
合并成一个控制点 `ratio=PeakRatio, height=Clearance`，随后这两个旧属性被移除。
**旧图纸的形状因此完全不变**（单点即旧弧顶）。

## 5. 位置约束与自动保护

样条插值要求 `x` **严格递增**，因此代码会做以下处理（`core.loop_profile()`）：

1. **排序**：按 `ratio` 从小到大稳定排序（并列时保持输入顺序）；
2. **夹紧**：`ratio` 夹到 `[0, 1]`，再整体压到 `(0, span_x)` 内；
3. **最小间距**：相邻点的 `x` 至少间隔 `0.002·span_x`；点太多导致放不下时**自动
   缩小该间距**（而不是报错），保证严格递增；
4. **进出线约束**：`B` 的水平分量被夹到**第一个**控制点之前 2% 余量，`D` 夹到
   **最后一个**控制点之后 2% 余量；
5. 列表为空时退化为 4 个点的弧线（A、B、D、E）。

> 实测（`span_x = 1 mm`）：输入 `0.5,0.2;0.5,0.3;-1,0.1;2,0.1`（并列 + 越界）后
> 得到 `x = 0.0001, 0.0001, 0.5, 0.502, 0.9999, 0.9999`，**严格递增**。

> 另有 `span_x > 0` 的硬性要求：两焊盘必须沿水平方向错开。若起点焊盘平面与走线
> 平面平行（交线不存在），`horizontal_frame()` 直接报错。

## 6. 特性与取舍

**优点**

* **参数含义直观**：直接设定进出线角度与控制点位置，与工艺语言一致；
* **形状自由**：`N` 个控制点即可描述平顶、直线下降等参考图特征；
* **向后兼容**：单点与旧 `(PeakRatio, Clearance)` 逐位等价，旧图纸自动迁移；
* 距离 `AB` 与 `ED` 精确等于 `LeadDistance`（不受角度影响）。

**代价**

* 控制点越多，样条在点间越容易出现轻微过冲（`v` 略高于设定的最高点）；
  实测单点方案最高点误差仅 **+0.0%~+0.8%**；
* 平顶/直线下降需要**用户自己布置多个点**（插件不再有 `TopLength` 之类的预设）。
